JSON Format Guide
Format 1: Power Automate Teams Export (Recommended)

Export messages directly from Power Automate — auto-detects title, assignee, service, status:

{
  "value": [
    {
      "id": "message-id",
      "channelId": "19:abc123@thread.tacv2",
      "conversationId": "19:abc123@thread.tacv2",
      "createdDateTime": "2026-06-01T09:15:00Z",
      "from": {
        "user": {
          "displayName": "Engineer A"
        }
      },
      "body": {
        "content": "Phục hồi DNS Cloudflare cho site chính...",
        "contentType": "html"
      },
      "subject": null
    }
  ]
}
Format 2: Simple Tasks

Manual format with explicit fields:

{
  "tasks": [
    {
      "title": "Task name",
      "description": "Optional details",
      "service": "Kubernetes",
      "assignee": "Engineer A",
      "requester": "Boss Name",
      "estimate_hours": 2.5,
      "status": "Open",
      "created_at": "2026-06-01"
    }
  ]
}

Status convention: Add [DONE], [BLOCKED], or [OPEN] at the end of your message. Parser detects this tag and sets status automatically. No tag = Open.
Supported tags: [DONE] [XONG] [HOÀN THÀNH] → Done · [BLOCKED] [TẠM DỪNG] [VƯỚNG] → Blocked · [OPEN] [ĐANG LÀM] → Open
Duplicate detection: same source_id (message ID) OR same title+assignee → skipped.
