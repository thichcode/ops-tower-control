JSON Format Guide
Format 1: Power Automate Teams Export (Recommended)

Export messages directly from Power Automate — auto-detects title, assignee, service, status:

{
  "value": [
    {
      "id": "message-id",
      "channelId": "19:abc123@thread.tacv2",
      "conversationId": "19:abc123@thread.tacv2",
      "createdDateTime": "2026-06-01T09:15:00Z",
      "from": {
        "user": {
          "displayName": "Engineer A"
        }
      },
      "body": {
        "content": "Phục hồi DNS Cloudflare cho site chính...",
        "contentType": "html"
      },
      "subject": null
    }
  ]
}
Format 2: Simple Tasks

Manual format with explicit fields:

{
  "tasks": [
    {
      "title": "Task name",
      "description": "Optional details",
      "service": "Kubernetes",
      "assignee": "Engineer A",
      "requester": "Boss Name",
      "estimate_hours": 2.5,
      "status": "Open",
      "created_at": "2026-06-01"
    }
  ]
}

Power Automate auto-detection: title from first line/subject, assignee from from.user.displayName, service from keywords (Kubernetes/Cloudflare/Backup/...), status from keywords (done/blocked/open).
Supported keys: value[], messages[], tasks[], or single message object.
Defaults: status=Open, work_type=Other, source=Teams, created_at=now. Duplicate detection: same title+assignee OR same source_id → skipped.
