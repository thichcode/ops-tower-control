JSON Format Guide

Each team member collects their Teams messages, summarizes tasks, and saves as JSON:

{
  "tasks": [
    {
      "title": "Task name",
      "description": "Optional details",
      "service": "Kubernetes",
      "work_type": "Incident",
      "assignee": "Engineer A",
      "requester": "Boss Name",
      "estimate_hours": 2.5,
      "status": "Open",
      "created_at": "2026-06-01"
    }
  ]
}

Fields: title (required), description, service, work_type, assignee, requester, requester_email, estimate_hours, actual_hours, status (Open/Done/Blocked), blocked_reason, created_at, completed_at, source_url, source_id.
Defaults: status=Open, work_type=Other, source=Manual, assignee=None, created_at=now. Duplicate tasks (same title+assignee) are skipped.
